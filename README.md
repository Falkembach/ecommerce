# Essência — loja online

Estrutura inicial de uma página de e-commerce feita com HTML e CSS.

## Estrutura

```text
.
├── index.html
└── assets/
    ├── css/
    │   └── styles.css
    └── images/
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador. A página é responsiva e não precisa de processo de build.

Os espaços de produto e o destaque principal são ilustrados com CSS; coloque imagens reais em `assets/images/` quando estiverem disponíveis.
